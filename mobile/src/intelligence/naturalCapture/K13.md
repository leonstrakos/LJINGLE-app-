# K13 — Natural Capture

K13 converts casual user statements into typed facts.

Safety boundary:

1. deterministic K8 gets first refusal;
2. K9/K11 handle explicit language actions;
3. K13 handles casual capture statements;
4. K10/K12 resolve target hints to real entities;
5. domain adapters decide whether/how a fact maps to storage;
6. the model never emits DB ids, SQL, table names, or mutations.

K13.0 is intentionally interpretation-only. Wire each domain executor only after
fixture tests demonstrate correct semantics for that domain.
