# K13.2 — Intelligence Torture Test

The corpus covers:
- deterministic K8 commands
- compound K11 requests
- K13 natural capture
- K9 messy-language fallback
- Croatian / English / mixed language
- typos
- pronouns and discourse
- ambiguous references
- SQL / fake-ID adversarial input
- deliberate non-commands

Two test modes exist:

1. deterministic ownership
   - local model disabled
   - verifies K8 and intentional unresolved behavior

2. full ownership
   - runs in an LJingle native development build
   - verifies K9/K11/K13 routing with the actual on-device model

This suite tests interpretation ownership, not database execution.
Executor/domain tests remain separate so a parser failure is distinguishable from
a storage failure.
