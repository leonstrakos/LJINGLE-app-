# K13.3 — Safe Domain Adapters

K13.3 is the boundary from validated Natural Capture facts to existing LJingle
domain APIs.

Execution requires an already-resolved real entity.

Rules:
- BOOK percentage/fraction progress can update book progress.
- BOOK finish/start/pause can update status and dates.
- MEDIA percentage/fraction progress can update media progress.
- MEDIA finish/start can update status and dates.
- SERIES episode counts may mark the next N unwatched regular episodes, but
  ALWAYS require confirmation.
- Historical episode facts store the resolved historical date via setWatchedAt.
- PAGE/CHAPTER facts are not converted to percentages without a known total.
- DURATION_MINUTES is not converted to progress; it needs a later backdated
  session adapter.
- Approximate dates/progress require confirmation.

The model still cannot execute this layer or provide entity ids.
