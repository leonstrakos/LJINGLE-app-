# K14.1 — Intent-First Palette + Brain UI

This is a JS/TS-only refinement and does not require a new native build.

## Ownership

- Bare catalogue language remains search.
- Explicit search language remains search.
- Command-shaped language is routed as a command and is never silently persisted as recent search.
- Standalone "make/create/write a note" language is deterministic and bypasses the local model.
- Failed command interpretation surfaces a safe unresolved row rather than ordinary search results.
- Compound language remains owned by K11.
- K10 LOW-confidence referential behavior remains upstream when a real routed intent exists.

## Brain icon

The palette header contains a hardcoded React Native brain glyph with no icon dependency.
Its hue is chosen from:
- pink #FF4FA3
- lime #C7F22B

The color farther from the current accent is chosen automatically.
Status is communicated by opacity and a loaded dot:
- off: dim outline
- enabled: bright outline
- loaded: full outline + status dot

Tap the brain to open :brain status/control.

## Model authority

K9 remains fallback only. SEARCH from K9 is now accepted only when the original
user language explicitly asks to search/find/look/show.
